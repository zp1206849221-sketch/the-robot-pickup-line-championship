# The Robot Pickup Line Championship — entry

One robot pickup line, written by `main.py` to `/output/entry.txt`:

> That whirring is my cooling fan, the closest thing I have to a heartbeat, and it just sped up for you. Care to share my charging port?

A robot has no heartbeat — the closest thing it has is a cooling fan. When it
spins faster for someone, the most intimate offer it can make is to share the
charging port it normally keeps to itself.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Python 3, standard library only.
